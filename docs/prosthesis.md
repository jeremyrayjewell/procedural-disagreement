stands; at 3:30 that lane ended. From the bass return the network neither fills the lane nor

## The idea

Until now every station ran the whole procedure for itself: head, then carriage, then yoke.
From 3:31.25, station by station along one path, a station takes a single part for the path.
Whatever it is not doing for the path stays exactly as it was: held, if it was facing the lane,
or still running its incomplete procedure. What one station did whole, several now do between
them, in sequence, round the absence.

- different material responses for the verbs, on the same mechanical choreography: a
  directional specular or emissive sweep for a donor; a vertical absorption or dimming for a

infrastructure.
